# PS5-ECAM builds

The app folder for the PS5, zipped: extract it and copy `PPSA99360` to `/data/homebrew/PPSA99360`
(see the project's [README](https://github.com/premohq/PS5-ECAM#install)). PS5-ECAM was called
PS5CEMU-HAR until 5.0.0, so the builds before it have that name.

`SHA256SUMS` has each file's checksum. `PS5CEMU-HAR-v5.1.0.zip` is the same file as `PS5-ECAM-v5.1.0.zip`
(and the 5.0.1 and 5.0.0 pairs the same), under the name the app's updater looks for up to 4.0.1, so those installs
update from inside the app.
